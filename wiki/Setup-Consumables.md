# Consumables

List the colours a multi-pass printer prints with, and what each costs.
Skip this page if you have no multi-pass printer.

## Before you start

- Set the printer up as multi-pass on [Printers](Setup-Printers).
- Check that the printer's consumable type, such as Risograph, is in the
  **Consumable types** list on Settings.

## Add a colour

1. Open the **Consumables** sheet and click **Add row**. The new row gets its
   **ColourID**.
2. Choose the **Consumable type**. It must match the printer's.
3. Type the **Colour**, such as `Fluorescent Pink`.
4. Type the **Cost per m2**, for typical coverage.
5. Leave **Active** as Yes.

## Result

When you add a colour pass to a job on that printer, the colour appears in
the pass's **Colour** drop-down. See [Colour passes](Jobs-Colour-Passes).

## Things to know

- A pass offers only the colours of its printer's consumable type, so two
  printers of different types never mix up colours.
- Each pass keeps the cost per m2 its colour had when the pass was added.
  Later price changes do not alter it.
- When a colour is discontinued, set **Active** to No rather than removing or
  renaming the row.
