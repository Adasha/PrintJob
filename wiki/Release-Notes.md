# Release notes

What changed in each version, newest first, for people using the workbook.
To move to a new version, see [Upgrading](Admin-Upgrading). The full
technical history is in the project's `docs/CHANGELOG.md`.

> **Mac:** use 0.11.1 or later. Before 0.11.1, Export, Export report and
> Backup on a Mac could delete the workbook.

## 0.11

| Version | What changed |
| --- | --- |
| 0.11.5 | **Summary** shows the Chargeable figures again; they had been hidden as ####. **Unit** and **Area m2** can no longer be typed over on new jobs. A whole quantity shows as 100, not "100." |
| 0.11.4 | **Add print room...** refuses a code another room already has, and suggests a free one. Before, a new room could take an existing room's code and give out the same Job IDs. Colour passes: **Passes** and **Pass** can no longer be typed over, and **Remove** keeps you on the room's sheet. Settings has a **PrintJob on GitHub** link |
| 0.11.3 | A room's **Sheet status** shows again; the Export line had been covering it |
| 0.11.2 | New **Rename print room...** on Settings, which renames the tab too. A new job fills in its Unit when its paper comes from the room's default. On a Mac, **Remove print room...** asks for the room's name again |
| 0.11.1 | Mac: Export, Export report and Backup no longer risk deleting the workbook |
| 0.11.0 | Multi-pass printers: colour passes, a set-up cost per pass, and the Consumables sheet |

## 0.10

| Version | What changed |
| --- | --- |
| 0.10.31 | **University subsidy** on Settings, shown on Reports |
| 0.10.30 | The **Departments** sheet: free departments, and reporting by department |
| 0.10.29 | **Plan a print job** on Summary: price a job before recording it |
| 0.10.25 to 0.10.28 | Reports: **Go to record**, **Clear all filters**, more filters, and the filters moved to a block on the left |
| 0.10.23, 0.10.24 | **Restore workbook...** creates missing print rooms, and can read an older copy of the workbook |
| 0.10.17 to 0.10.20 | Exports ask whether to include student names; exports and file pickers work on a Mac |
| 0.10.12 to 0.10.14 | All, Reduced and Minimal column views, and **Hide cost detail** |
| 0.10.0 to 0.10.4 | Printer and paper compatibility by size; built-in student-supplied paper; **Clear table**; IDs carry the site code |

Versions before 0.10 are in `docs/CHANGELOG.md`.
