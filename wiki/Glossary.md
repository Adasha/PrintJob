# Glossary

| Term | Meaning |
| --- | --- |
| **Active** | Yes means a technician, printer, paper, colour or department is offered for new jobs. Set it to No instead of deleting the row |
| **Chargeable Cost** | What the job costs the student or department: the Gross Cost less anything disregarded |
| **Colour pass** | One colour printed on a multi-pass printer, recorded as its own row under the job. See [Colour passes](Jobs-Colour-Passes) |
| **Consumable** | The ink, toner or other material a printer uses, costed per square metre |
| **Consumable type** | A kind of consumable, such as Ink, Toner or Risograph. Printers and colours each have one |
| **Department** | A department listed on the Departments sheet. A job counts as that department when its Student Name is the department's name or alias |
| **Disregard** | Not charging the paper or the consumable part of a job. The cost is still counted, under Disregarded |
| **Export status** | The **Export** line on a room's side panel: whether the room has been exported, and how many changes since |
| **Free department** | A department whose jobs are costed but not charged |
| **Frozen prices** | The prices copied onto a job when it is recorded, so later price changes do not alter it |
| **Gross Cost** | Paper, consumable and set-up cost together, before anything is disregarded |
| **ID** | The code each technician, printer, paper, colour and department gets, such as `UNI-PRN-0003`. Never typed, never reused |
| **Job ID** | A job's unique code: site, room code and number, such as `UNI-PHOTO-00042` |
| **Multi-pass printer** | A printer that prints one colour at a time, such as a Risograph |
| **Print room** | A room with its own sheet of jobs. The workbook sometimes calls it a location |
| **Refresh Locations** | The command that finds every print room sheet and brings the reports up to date with them |
| **Roll length unit** | Whether a room types roll lengths in metres or centimetres |
| **Room code** | The short code in a room's Job IDs, such as `PHOTO`. Each room has its own, and it never changes |
| **Schema version** | The version of the job record's shape, such as 1.4 |
| **Sheet status** | The result of **Check this sheet**, on a room's side panel |
| **Site ID** | The short code for the whole workbook, at the start of every ID |
| **Standard size** | A named sheet size, such as A3, listed on Settings |
| **Status** | A job's own check: OK, or what is wrong |
| **Student-supplied paper** | Paper the student brings, recorded as **Supplied (Roll)**, **Supplied (Sheet)** or a paper marked **Supplied by student** |
| **Subsidy** | The percentage of chargeable cost the university pays, shown on Reports |
| **Template cost** | The set-up cost of one colour pass on a multi-pass printer |
| **Workbook version** | The release of the workbook, such as 0.11.5. Shown by **About** |
