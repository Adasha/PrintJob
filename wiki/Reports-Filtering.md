# Filtering

Find jobs from every print room on the **Reports** sheet, narrow them down
and sort them.

## Find jobs

1. Open the **Reports** sheet.
2. Type or choose a value in any filter box on the left. The list updates as
   you type; there is no search button.
3. Add more filters to narrow it further. Every filter you set must match.
4. To start again, click **Clear all filters**.

## The filters

| Filter | Shows jobs where |
| --- | --- |
| **Student/dept. name** | the name contains what you type, in any case |
| **Student number** | the number matches exactly |
| **Department** | the job counts as that department. See [Departments](Setup-Departments) |
| **From date**, **To date** | the job falls on or between these dates |
| **Min cost**, **Max cost** | the chargeable cost is within this range |
| **Paid** | Yes: marked paid. No: not marked paid |
| **Has a problem** | the job's Status is not OK (Yes) or is OK (No) |
| **Disregarded** | the paper, the consumable, both or neither is disregarded |
| **Location (print room)**, **Technician**, **Printer model**, **Paper stock** | the job matches the choice |
| **Printer type** | single pass or multi-pass |
| **Paper type** | roll or sheet |
| **Student-supplied paper** | the student brought the paper (Yes) or not (No) |
| **Has notes** | the job has notes (Yes) or not (No) |

Leave a box empty to ignore it.

## Sort the list

Choose a column in **Sort by** and a **Sort direction**.

## Read the results

- **Matching** shows the number of jobs and their Gross, Disregarded,
  Chargeable, Paid and Unpaid totals.
- **After ...% subsidy** shows the chargeable amount less the **University
  subsidy** set on Settings. At 0% it is the same as Chargeable.
- **By print room**, **By paper stock** and **By department**, to the right of
  the list, break the matching jobs down.

## Go to a job

1. Click any cell in the job's row.
2. Click **Go to record**, under **Selected record:**.

The job's print room sheet opens with the job selected.

## Things to know

- The list shows a few key columns. The others (printer, quantity, the cost
  detail, technician, notes) are hidden, not missing; unhide them the usual
  Excel way if you need them.
- To collapse the filters, click the **-** above the column letters.
- If you give a name and a number that never appear together, a warning says
  so.
- There is no calendar for the date boxes. Type the date.
